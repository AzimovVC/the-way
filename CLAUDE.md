# The Way

Мобильный PWA-трекер привычек. Центральная метафора: история пользователя рисуется как
одна дорога («путь»). Дни, в которые задачи выполнены, ведут дорогу вверх — к цели;
пропуски разворачивают её вниз, к анти-цели.

## Команды

```bash
npm run dev      # Vite dev-сервер (DevPanel доступна только здесь)
npm run test     # vitest run — инварианты геометрии пути
npm run lint     # oxlint
npm run build    # tsc -b && vite build
```

Перед коммитом: `npm run lint && npm run test && npm run build`.

## Стек

React 19 + TypeScript + Vite 8, Tailwind 4 (через `@tailwindcss/vite`, без конфиг-файла),
react-router-dom 7, vite-plugin-pwa (autoUpdate). Бэкенда нет — всё состояние в localStorage.

## Архитектура

Слои разделены строго, и это разделение стоит сохранять:

- **`src/domain/`** — чистый TypeScript, без React и без DOM. Вся геометрия, все правила.
  Тестируется напрямую.
- **`src/state/AppStateContext.tsx`** — единственный источник состояния приложения.
  `setState` всегда пишет в localStorage; отдельного стора нет.
- **`src/storage/appStorage.ts`** — сериализация в localStorage, debounce 400 мс,
  принудительный сброс на `beforeunload`/`pagehide`.
- **`src/components/Имя/Имя.tsx`** + `index.ts` — конвенция для всех компонентов.
- **`src/screens/`** — три маршрута: `/` (путь), `/stats`, `/profile`.
- **`src/dev/`** — DevPanel, рендерится только при `import.meta.env.DEV`.

## Движок пути — главная подсистема

[src/domain/pathEngine.ts](src/domain/pathEngine.ts) строит дорогу как **кривую, заданную
кривизной и проинтегрированную по длине дуги** ([pathCurve.ts](src/domain/pathCurve.ts)),
а не как последовательность смещённых точек. Это даёт три свойства, ради которых модель
и существует:

1. **точный шаг** — каждый слот ровно `DAY_SPACING_PX` дуги от предыдущего;
2. **ограниченный поворот** — суммарная кривизна зажата в `MAX_TURN_PER_DAY_DEG`;
3. **отсутствие самопересечений** — следует из (2): радиус разворота физически не даёт
   дороге вернуться в собственную колонну.

Все влияния (декоративная волна, тренд, уклонение от старой истории, выпрямление под
чипом вехи) складываются **как кривизна** и затем зажимаются. Никогда не сдвигайте уже
поставленную точку вбок — это ломает и шаг, и гладкость.

Константы живут в [src/domain/config.ts](src/domain/config.ts) и подробно откомментированы:
большинство чисел **выведены**, а не подобраны на глаз. Комментарий объясняет вывод —
читайте его прежде, чем менять значение.

Подробный рабочий процесс: см. скилл `path-geometry`.

## Хранение состояния

Конверт в localStorage — `{ version: 1, state }` под ключом `the-way:v1`.
**Сейчас миграций нет: любое несовпадение версии молча стирает прогресс пользователя.**
Прежде чем менять формы в [models.ts](src/domain/models.ts), см. скилл `state-migration`.

## Соглашения

- Даты — строки `YYYY-MM-DD`. Логический день закрывается в 3:00 локального времени
  (`DAY_BOUNDARY_HOUR`), а не в полночь; всегда берите «сегодня» через `getLogicalToday`.
- Состояние обновляется иммутабельно; после любого изменения `days` прогоняйте
  `applyPathGeometry`, иначе геометрия дня разойдётся с данными.
- Точка с запятой не ставится, кавычки одинарные — следуйте окружающему коду.
- Комментарии объясняют **почему**, а не что. Числу с неочевидным происхождением нужен
  вывод, а не подпись.
